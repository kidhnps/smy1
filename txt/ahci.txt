Acer（宏碁）的筆記型電腦與桌上型電腦在 BIOS 中切換 AHCI 模式，經常會遇到「找不到 SATA Mode 選項」的情況。這是因為 Acer 預設將此隱藏功能鎖定（通常默認為 RST with Optane 或 VMD 模式）。 [1, 2] 
必須在 BIOS 中按下隱藏熱鍵，才能順利將其解鎖並切換為 AHCI。
------------------------------
## ⚠️ 重要事前準備（必做）
若系統已有 Windows，直接改 AHCI 會導致無法開機並出現藍屏（Blue Screen）。 [1, 2] 

   1. 進入 Windows，按下 Win + R 輸入 msconfig。
   2. 切換至「開機 (Boot)」分頁，勾選「安全開機 (Safe Boot)」並儲存。
   3. 重新開機，準備進入 BIOS。 [1] 

------------------------------
## 🛠️ 方案 A：Acer 筆記型電腦（解鎖隱藏選單）

   1. 開機時連續狂按 F2 鍵進入 BIOS 畫面。
   2. 使用鍵盤左右方向鍵，切換到 Main 分頁。
   3. 在此畫面上，同時按下鍵盤的隱藏熱鍵 Ctrl + S。
   4. 此時原本隱藏的 SATA Mode 或 VMD Controller 就會跳出來。
   5. 將其從原本的 Optane / RAID / VMD 更改為 AHCI。
   6. 按下 F10 鍵儲存並重啟離開。 [1, 2, 3, 4, 5, 6, 7, 8] 

------------------------------
## 🛠️ 方案 B：Acer 桌上型電腦（Veriton 系列等）

   1. 開機時連續狂按 Del (Delete) 鍵進入 BIOS。
   2. 進入 BIOS 後先按一次鍵盤的 F1 鍵。
   3. 移至頂部 Advanced ＞ 進入 Integrated Peripherals 選項。
   4. 如果有直接看到 Onboard SATA Mode，直接手動改為 AHCI。
   5. 如果沒看到，在此畫面同時按下 Ctrl + S（部分機種為 Ctrl + D）。
   6. 畫面上會跳出 VMD Controller 選項，將其設定為 Disabled (關閉)。
   7. 系統會跳出警示，選擇 OK，此時下方 SATA Mode 就會自動切換為 AHCI Only。
   8. 按下 F10 儲存並重新開機。 [9, 10, 11] 

------------------------------
## 🔄 改完後的最後步驟
改完重新開機後，系統會自動以剛剛勾選的「安全模式」啟動 Windows。進入系統確認能正常運作後，再次打開 msconfig，將「安全開機」取消勾選，再次重啟即可正常使用 AHCI 模式。 [1, 12] 
如果更改後無法正常回到 Windows，請問你的電腦型號是什麼？我可以幫你查詢該型號特定的 Intel VMD 關閉方法。




華碩（ASUS）電腦與筆電切換 AHCI 模式（或是關閉 Intel VMD 晶片以改回 AHCI 模式）的設定位置跟 Acer 不同，華碩通常不需要按隱藏熱鍵，而是放在 Advanced（進階） 分頁內。
------------------------------
## ⚠️ 重要事前準備（必做）
如果硬碟已有 Windows 系統，直接更改 AHCI 會因為缺乏驅動程式而導致藍屏。

   1. 在 Windows 內按 Win + R 輸入 msconfig。
   2. 切換到「開機」分頁，勾選「安全開機」並儲存。
   3. 重新開機，準備進入 BIOS。

------------------------------
## 🛠️ 華碩桌上型電腦 / 早期筆電（更改 AHCI）

   1. 開機時連續狂按 Del 或 F2 進入 BIOS。
   2. 按下 F7 鍵進入 Advanced Mode（進階模式）。
   3. 切換到頂部的 Advanced（進階） 分頁。
   4. 找到並進入 SATA Configuration（SATA 設定）。
   5. 找到 SATA Mode Selection 項目，將其從 RAID/IDE 改為 AHCI。
   6. 按下 F10 鍵儲存並重啟離開。

------------------------------
## 🛠️ 華碩新世代電腦（Intel 11代以上 CPU 筆電與主機板）
新版 Intel 平台改用 VMD 技術，BIOS 內常找不到 SATA Mode，必須透過關閉 VMD 來啟用 AHCI。

   1. 開機連續狂按 F2 進入 BIOS。
   2. 按下 F7 進入 Advanced Mode（進階模式）。
   3. 切換到 Advanced（進階） 分頁。
   4. 找到並進入 VMD setup menu（VMD 設定選單）。
   5. 將 Enable VMD controller 改為 Disabled（關閉）。
   6. 系統會跳出警告視窗，點選確認，此時底層會自動回歸並改為 AHCI 模式。
   7. 按下 F10 儲存並重新開機。

------------------------------
## 🔄 改完後的最後步驟
改完重啟後，電腦會自動以「安全模式」進入 Windows。順利進入桌面後，再次打開 msconfig，將「安全開機」取消勾選，然後正常重新開機一次就完成了。
如果找不到 VMD 選項，請問你的華碩主機板或筆電的完整型號是什麼？我可以幫你對照該型號的 BIOS 畫面。
